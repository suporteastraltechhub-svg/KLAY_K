## Goal

## Constraints & Preferences
- Não remover funcionalidades existentes; não quebrar autenticação/banco/navegação.
- Analisar arquitetura antes de mudanças grandes; reutilizar serviços existentes (LiveKitService, GiftService, SocialService, ContentService, SupabaseService, founder_service, guardian_service, KlaykTheme/KlaykColors, KlaykUx).

- Performance = prioridade máxima: evitar rebuilds desnecessários, listas de chat otimizadas, avatares com cache, realtime (sem mock); honrar ExperienceSettings (reduceAnimations/reduceEffects).
- KLAY K Security Max: permissões/regras no backend (`has_perm`/`write_audit`/security definer), não apenas esconder botões; não coletar dados desnecessários; não prometer segurança perfeita; denúncias com status/histórico.
